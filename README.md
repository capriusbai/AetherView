# AetherView

Public installers and signed automatic-update feed for AetherView.

Source code is private. This repository does not contain project source, protocol codebooks, standard documents, or signing private keys.

See [Releases](https://github.com/capriusbai/AetherView/releases) for verified binaries. Ubuntu amd64 DEB and AppImage packages are planned; only published release assets are delivered versions.
